# План презентації проєкту

1. **Назва:** вебдодаток «Кулінарна книга».
2. **Мета:** створити простий сайт для перегляду кулінарних рецептів.
3. **Технології:** Python, Flask, HTML, CSS та JavaScript.
4. **Структура:** показати `app.py`, папку `templates` і папку `static`.
5. **Функціональність:** продемонструвати два рецепти з фотографіями.
6. **Інтерактивність:** показати пошук, фільтр категорій і відкривання опису.
7. **Тестування:** коротко розповісти про перевірки з файлу `testing.md`.
8. **Розподіл роботи:** кожен учасник пояснює свою частину.
9. **Висновок:** сайт запускається локально та виконує поставлені завдання.
