# Розподіл обов'язків у команді

Для команди з 2–4 учасників ролі можна розподілити так:

1. **Учасник 1 — Python та Flask:** налаштування застосунку, маршрут головної сторінки, передавання рецептів.
2. **Учасник 2 — HTML:** структура сторінки, картки рецептів, поля пошуку та вибору категорії.
3. **Учасник 3 — CSS та фотографії:** оформлення сторінки, адаптивність, підготовка зображень.
4. **Учасник 4 — JavaScript і тестування:** пошук, фільтрація, відкривання опису, перевірка роботи сайту та документація.

Якщо в команді двоє людей, кожен бере на себе по дві суміжні ролі.
Якщо троє — четверту роль можна об'єднати з роллю учасника 2 або 3.
